# observations

this directory contains ground-truth annotations and the outputs generated by the pipeline.

## structure

- `*_ground_truth.rttm` -- original ami annotations used to automatically calculate the diarization error rate (DER).
- `outputs/enhanced_*.wav` -- the cleaned audio from phase 1.
- `outputs/diarization_*.json` -- pyannote's speaker timestamps (from phase 2).
- `outputs/diarization_*.rttm` -- standard format predictions.
- `outputs/transcript_*.txt` -- the final smart-transcription texts (from phase 3).
- `evaluation_notes.md` -- phase 1 and phase 2 evaluation notes and bug tracking.
- `phase2.5_validation.md` -- phase 2.5 validation experiment tracking (ablation study).
- `phase3_validation.md` -- phase 3 validation notes for the Segment-Level Dual Path architecture.

## inspection instructions
to test the enhancement suite independently:
```bash
python -m pytest tests/ -v -s
```

to run the full end-to-end pipeline (enhancement + diarization + dual-path transcription):
```bash
python run_pipeline.py --input observations/small_test_sample.wav --output-dir observations/outputs --transcription-model large-v2 --transcription-device cuda --transcription-compute float16
```
